## 自己 PR

Go に 2018 年頃に出会って、2021 年頃から本格的に学習してきました。
主には、Cobra という CLI ツール作成ライブラリで CLI ツールを作成したり Gin という Go の Web フレームワークで Web API を作成したり Ebitengine という Go 製 2D ゲームエンジンでゲームを作成したりして、一通り Go がよく使われる用途において開発を行ってきました。ようやく今年、GoConference2024 に参加することもできて、Go へのモチベーションも高い状態となっています。

業務においては、CLI ツールによるタスクの効率化や Scenarigo による E2E テストの導入などを行うなど、開発だけでなく CI/CD や IaC の構築やリファクタにも知見、興味があり開発プロセスの改善にも貢献することが可能です。

・好きな標準パッケージ：net/http
・your work for gophers のスキルレベル：レベル 3 https://yourwork.knowledgework.com

開発以外においては、アウトプットにも力を入れており外部、内部問わず LT の登壇や勉強会の主催を行なっています。グループ会社横断の技術イベントを企画しておりイベントが大好きな人間です。
